BentoBox 3.22.2 是服务器的空岛核心框架。除核心玩法外，它还由多个附属插件提供岛屿等级、银行、边界、飞行、魔法刷石机等扩展功能。本服已加载 7 个 BentoBox 附属，它们都与 BSkyBlock 游戏模式无缝配合。

## 核心与游戏模式

| 插件 | 版本 | 作用 |
|------|------|------|
| BentoBox 核心 | 3.22.2 | 空岛框架，管理岛屿创建、队伍、保护范围、权限与数据库 |
| BSkyBlock（游戏模式） | 1.20.0 | 经典的「虚空一岛」玩法：开局一座小岛，全靠发展成空中要塞 |

主命令 `/is`（别名 `/island`、`/sb`）负责进入岛屿界面。

## Level：岛屿等级

岛屿等级按岛上所有方块的价值总和计算，是最直观的实力与财富指标。

| 等级 | 方块值范围 | 说明 |
|------|-----------|------|
| 默认 | 0 ~ 500 | 起步阶段 |
| 铁 | 500 ~ 2,000 | 初级发展 |
| 金 | 2,000 ~ 10,000 | 中期发展 |
| 钻石 | 10,000 ~ 50,000 | 高级发展 |
| 大师 | 50,000+ | 顶级发展 |

关键机制：

| 参数 | 值 | 说明 |
|------|----|------|
| 计算公式 | 方块值 / 100 | 每 100 方块值 = 1 级 |
| 死亡惩罚 | 100 方块值/次 | ≈ 死亡一次掉 1 级（掉经验不掉辻币） |
| 计算冷却 | 60 秒 | 频繁查看等级会触发冷却 |
| 新建/重置岛屿 | 归零 | 新岛从 0 开始算 |
| 下界/末地计入 | 关闭 | 目前只算主世界方块的等级 |

`/is level` 查看当前岛屿等级。提升等级的方法：放置高价值方块（钻石块、下界合金块等）、用魔法刷石机产出稀有矿、扩展岛屿面积、接受他人 `/is donate` 捐赠方块。

## Bank：岛屿银行

岛屿队伍共用的存款系统，供全队存取辻币。

| 参数 | 值 |
|------|----|
| 年利率 | 1.0（1%） |
| 复利周期 | 1.0 |
| 存取冷却 | 60 秒 |
| 成员操作提醒 | 开启（他人存取时会通知全队） |

| 命令 | 功能 |
|------|------|
| `/is bank` 或 `/bank` | 打开岛屿银行 |
| `/is bank deposit <金额>` | 存款 |
| `/is bank withdraw <金额>` | 取款 |

## Border：岛屿边界

可视化你的岛屿保护范围，方便了解哪里安全、哪里会被他人破坏。

| 参数 | 值 |
|------|----|
| 边界类型 | VANILLA（原版边界） |
| 显示颜色 | 蓝色（BLUE） |
| 默认显示 | 开启 |
| 反弹投掷物 | 开启（越界投掷的物体会被弹回） |
| 传送回界 | 开启 |
| 显示最大边界 | 开启 |

`/is border` 显示/隐藏岛屿边界。岛屿保护范围默认为 50 格（距岛中心），边界可帮你判断贵重设施是否已超出保护范围。

## IslandFly：岛内飞行

允许你在岛屿范围内飞行，极大方便建岛与探索。

| 参数 | 值 |
|------|----|
| 解锁等级 | 岛屿等级 500 |
| 出界关闭 | 5 秒（离开岛屿范围 5 秒后飞行自动关闭） |
| 离开保护范围可用 | 关闭（默认需在保护范围内） |

`/is fly` 开启/关闭岛内飞行。

## InvSwitcher：进出岛背包切换

在进入自己的岛屿与离开岛屿（回到主城/公共区域）时，自动切换到对应的背包与随身物品，让「岛内建设」「岛外经营」两套装备互不干扰。无需手动操作，适合岛内一套矿物/建材装备、岛外一套战斗/经营装备的玩法。

## MagicCobblestoneGenerator：魔法刷石机

让刷石机产出矿石与稀有材料，是本服最重要的资源来源之一。

| 关键点 | 值 |
|--------|----|
| 每岛可同时激活 | 3 台 |
| 档位解锁 | 按岛屿等级（0→250 级共 7 档） |
| 最高档产出 | 钻石 10% / 绿宝石 8% / 金 12% / 红石 16% 等 |
| 下界档 | 石英矿 / 远古残骸 / 金矿 |

完整机制与概率表见站内另一篇《魔法刷石机玩法指南》。

## 如何查看已装附属

| 命令 | 功能 |
|------|------|
| `/bsbadmin` | 打开 BSkyBlock 管理面板（含附属管理） |
| `/island admin` | 查看空岛管理员相关命令 |
| `/bank` | 打开岛屿银行 |
| `/is border` | 查看岛屿边界 |
| `/is fly` | 开启岛内飞行 |
