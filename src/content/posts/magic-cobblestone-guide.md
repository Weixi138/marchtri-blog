魔法刷石机（Magic Cobblestone Generator）是 BentoBox 空岛附属插件，让普通的「水源 + 岩浆」刷石机不仅能产圆石，还能自动产出多种矿石与稀有材料，是你空岛发展的核心资源来源。

## 是什么

默认的刷石机（水流 + 岩浆流相遇）只会产圆石。而魔法刷石机让同一台刷石机在生成方块时，有机会刷出煤炭、铁矿、金矿、红石、绿宝石、钻石甚至下界合金等矿石。

你不需要改造刷石机的结构，只需要对着刷石机右键，在弹出的菜单里选择你要激活的档位即可。

## 怎么开启

1. 先搭好一个普通刷石机（水流 + 岩浆流相遇之处，会生成石头/圆石）。
2. 对着刷石机右键，打开「魔法刷石机」菜单。
3. 在菜单里选择一个已解锁的生成器（档位），点击激活。
4. 激活后，刷石机每生成一个方块，就会按该档位的概率表产出对应矿石。

主命令：`/is generator view` 查看已购买/激活的生成器详情；`/is generator activate` 激活/停用生成器。

## 每岛上限

| 项目 | 默认值 |
|------|--------|
| 每岛可同时激活的生成器数量 | 3 个 |
| 是否需要玩家在附近 | 默认不限制距离 |

当激活数量达到上限时，可先停用旧的，再激活新的。

## 档位与解锁等级

魔法刷石机的产出由生成的档位决定，档位越高能刷出的矿石越稀有。大多数高档位需要你的岛屿等级（BentoBox Level）达到要求才能解锁购买。

| 档位 | 解锁岛屿等级 | 购买费（辻币） | 主要产出 |
|------|------------|------------|----------|
| 起始生成器 | 0（默认） | 免费 | 圆石 77% / 石头 10% / 煤 6% / 铁 2% |
| 煤生成器 | 20 | 5 | 圆石 60% / 煤 15% / 石 15% / 铁 3% |
| 铁生成器 | 50 | 5 | 铁 18% / 石 20% / 圆石 45% / 煤 10% |
| 金生成器 | 100 | 5 | 铁 22% / 金 15% / 石 20% / 圆石 30% |
| 红石生成器 | 150 | 5 | 铁 22% / 金 14% / 红石 13% / 石 20% |
| 绿宝石生成器 | 200 | 5 | 铁 22% / 红石 18% / 金 15% / 绿宝石 8% |
| 钻石生成器 | 250 | 5 | 铁 25% / 红石 16% / 金 12% / 钻石 10% / 绿宝 8% |

几点说明：

- 「起始生成器」是默认档位，无需等级、无需购买，开局即可用，会固定产出少量煤和铁，保证新手能攒下第一批资源。
- 各档位剩余的百分比由圆石/石头/砂砾/花岗岩/闪长岩/安山岩构成，随着档位提升，基础材料占比持续走低、稀有矿占比升高。

## 下界与末地生成器

除了主世界的刷石机，下界（玄武岩刷石机）和末地也有专属档位。

下界生成器：

| 档位 | 说明 |
|------|------|
| 起始下界生成器 | 默认档位，玄武岩 80% / 下界岩 19% / 沙砾 1% |
| 下界生成器（等级 100） | 玄武岩 40% / 岩浆块 10% / 荧石 10% / 下界石英矿 5% / 远古残骸 0.01% / 金矿石 1% 等 |

下界生成器有概率刷出下界石英矿，极低概率刷出远古残骸（下界合金的来源），还会附带掉落金粒或下界合金碎片。

末地生成器（等级 100）：

| 产出 | 概率 |
|------|------|
| 末地石 | 60% |
| 黑曜石 | 20% |
| 紫珀块 | 15% |
| 末地石砖 | 5% |

## 宝物掉落

除了生成方块，刷石机在生成方块的一瞬间还有极低概率额外掉落一件「宝物」：

| 档位 | 宝物流 | 掉落概率 |
|------|--------|----------|
| 起始生成器 | 煤炭 | 0.1% |
| 起始下界生成器 | 金粒 | 0.1% |
| 铁生成器 | 金粒 | 0.1% |
| 金生成器 | 红石粉 | 0.1% |
| 红石生成器 | 绿宝石 | 0.01% |
| 绿宝石生成器 | 钻石 | 0.01% |
| 钻石生成器 | 钻石 | 0.1% |
| 下界生成器 | 金粒 / 下界合金碎片 | 0.1% |

## 进阶技巧

1. 前期（0 级）：直接用「起始生成器」，囤积圆石、石头，攒煤和铁，为后期升级做准备。
2. 中期（50~150 级）：升到「铁/金/红石生成器」，配合挖掘技能与加成，快速积累矿产。
3. 后期（200~250 级）：「绿宝石/钻石生成器」，这是你大部分钻石、绿宝石的来源。
4. 配合自动化：魔法刷石机配合漏斗、Slimefun 电力传输，可实现全自动矿石收集产线。
5. 注意保护范围：所有刷石机必须放在岛屿保护范围内（距岛中心 50 格），否则他人可破坏、也不会被 BentoBox 保护。

## 生成器类型差异

生成器在刷石机配方不同时对应不同「类型」，菜单会自动筛选：

| 类型 | 适用刷石机 |
|------|-----------|
| COBBLESTONE | 圆石刷石机（水 + 岩浆经典式） |
| STONE | 石头刷石机（特殊结构） |
| BASALT | 玄武岩刷石机（下界，灵魂沙 + 蓝冰） |
| COBBLESTONE_OR_STONE | 圆石与石头刷石机均可 |
| ANY / BASALT_OR_* | 兼容多种结构 |

菜单可用筛选按钮（ACTIVE / COBBLESTONE / STONE / BASALT / VISIBILITY）快速过滤你要查看的生成器。
