无规矩不成方圆。这份守则汇总了云の辻的行为规范，条目不多，但执行很严，进服前请完整读一遍。

## 红线：严禁开挂作弊

严禁任何形式的作弊行为，包括但不限于：矿物追踪（矿透）、非岛屿飞行、杀戮光环等作弊客户端或模组。

处罚没有商量余地：一经发现直接永久封禁，不予解封。用小号开挂同样按此处理，且**永久封禁 IP**，换号没有用。

## 红线：禁止恶意建造卡服机器

禁止建造任何恶意卡服的机器。这类设备会拖垮全服的 TPS，影响的是每一个人的游戏体验。

一旦引发卡顿，管理组会定位核查到具体坐标和设备，**直接清理相关设备**，不做预告。辛辛苦苦搭的自动化产线如果设计不当、被判定为卡服源头，会连 builds 一起被清，所以大型红石机器请控制规模、优化结构。

## 建造家园：先圈地，再建设

建造家园务必**先圈地，再进行建设**。空岛系统自带岛屿保护范围（距岛中心 50 格），你的建筑必须落在保护范围内才受保护；保护范围外的建筑不受保护，被破坏了无处申诉。

正确的顺序：创建岛屿后确认边界（`/is border`），在保护范围内规划布局，然后再动手施工，保护自己的建筑财产。

## 其他行为规范

**破坏与财产**

- 禁止破坏他人财产，包括建筑、箱子、农田与养殖场。
- 离开队伍不会失去岛屿进度，但也不要动已退出成员留在岛上的东西。

**经济**

- 禁止恶意刷钱：利用漏洞刷币将资产清零并封禁。
- 玩家商店标价合理，禁止恶意哄抬/压价，确保有库存，禁止出售作弊物品或漏洞物品。

**聊天与社交**

- 禁止刷屏。
- 尊重他人：禁止辱骂、歧视、骚扰。被骚扰可以用 `/is ban` 禁止对方进岛，情况严重联系管理员。

**PVP**

- 禁止恶意 PVP：不要在非 PVP 区域挑衅其他玩家。

## 违规后果

| 违规 | 后果 |
|------|------|
| 轻度 | 警告 + 禁言 |
| 中度 | 临时封禁（1~7 天） |
| 严重 | 永久封禁 |
| 利用漏洞 | 资产清零 + 永久封禁 |
| 开挂作弊 | 永久封禁不予解封，小号开挂封永久 IP |
| 恶意卡服 | 定位核查，直接清理相关设备 |

守则里没写的，不代表可以做。拿不准某件事是否违规时，先问管理员，别拿自己的存档赌。
