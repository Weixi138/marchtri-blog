**云の辻 Kum no Tsuji**，Minecraft 空岛服务器，Java 版 26.2。这篇指南写给每一位新老玩家，涵盖连接、注册、空岛生存、技能打工、经济、社交与全部玩法系统。

## 连接与注册

| 项目 | 说明 |
|------|------|
| 服务器地址 | `mc.22331.top` |
| 游戏版本 | Minecraft Java 版 26.2（不支持基岩版直连） |
| 默认端口 | `25565`（自动识别，无需手动填写） |
| 在线模式 | 离线模式（需 AuthMe 密码登录） |

连接步骤：

1. 打开 Minecraft Java 版（版本 26.2），进入「多人游戏」→「添加服务器」，地址填 `mc.22331.top`。
2. 首次进服注册：`/register <密码> <重复密码>`。
3. 后续登录：`/login <密码>`。
4. 登录后输入 `/is` 创建你的第一座空岛，开始游戏。

进服后可按 `Shift+F` 打开快捷菜单，或输入 `/cd` 打开主菜单。

## 创建你的空岛

登录后输入 `/is`（或 `/island`、`/sb`），系统会自动生成一座悬浮在虚空中的小岛，初始包含一棵树、草方块与泥土、一个刷石机（水源 + 岩浆）、一个箱子（内含基础工具）。

小贴士：不要急着挖掉刷石机，它是你前期唯一的圆石来源。

新手第一步清单：

| 步骤 | 做什么 | 命令/方法 |
|------|--------|-----------|
| 1 | 登录并创建空岛 | `/register` → `/is` |
| 2 | 打开菜单 | `/cd` 或 `Shift+F` |
| 3 | 砍树做工具 | 手撸木头 → 合成木板 → 工作台 |
| 4 | 扩展岛屿 | 用刷石机获取圆石 → 石质工具 |
| 5 | 种树 | 等树叶掉树苗 → 种下（不够别挖光树叶） |
| 6 | 设置家点 | `/sethome` |
| 7 | 签到领奖励 | `/sign` |
| 8 | 查看技能 | `/skills` |
| 9 | 去主城看看 | `/spawn` |

### 岛屿等级

岛屿等级由 BentoBox Level 插件按岛上所有方块价值评分：

| 等级 | 方块值范围 | 说明 |
|------|-----------|------|
| 默认 | 0 ~ 500 | 起步阶段 |
| 铁 | 500 ~ 2,000 | 初级发展 |
| 金 | 2,000 ~ 10,000 | 中期发展 |
| 钻石 | 10,000 ~ 50,000 | 高级发展 |
| 大师 | 50,000+ | 顶级发展 |

提升等级的方法：放置高价值方块（钻石块、下界合金块等）、用魔法刷石机产出稀有矿石、扩展岛屿面积、接受他人捐赠。

### 魔法刷石机

对着普通刷石机（水源 + 岩浆流）右键打开菜单，选择要生成的矿石类型。每岛默认最多 3 个激活刷石机。产出受岛屿等级限制：

| 档位 | 解锁等级 | 主要产出 |
|------|------|----------|
| 起始 | 0 | 圆石 77% / 石头 10% / 煤 6% / 铁 2% |
| 煤 | 20 | 圆石 60% / 煤 15% / 石 15% / 铁 3% |
| 铁 | 50 | 石 20% / 铁 18% / 圆石 45% / 煤 10% |
| 金 | 100 | 铁 22% / 金 15% / 石 20% / 圆石 30% |
| 红石 | 150 | 铁 22% / 金 14% / 红石 13% / 石 20% |
| 绿宝石 | 200 | 铁 22% / 红石 18% / 金 15% / 绿宝石 8% |
| 钻石 | 250 | 铁 25% / 红石 16% / 金 12% / 钻 10% / 绿宝 8% |

前期（0 级）即会固定产出少量煤和铁，让新玩家能积攒第一批资源。

## 经济与交易

### 双货币体系

| 货币 | 符号 | 获取方式 | 主要用途 |
|------|------|----------|----------|
| 辻币（主货币） | 辻（如：辻500） | 卖物品、打工、签到、任务、礼包 | 购买物品、缴税、传送费 |
| 云券（充值货币） | 云（如：云300） | 仅充值获得（管理员补发） | 皮肤、特效、称号 |

辻币与云券完全隔离，不能互相兑换，云券只能通过充值获得。

### 箱子商店（QuickShop）

创建商店：放一个箱子 → 手持要出售的物品 → 对着箱子左键点击 → 输入价格（辻币/个）→ 确认后箱子会显示价格标签。

购买：对着商店箱子右键点击购买 1 个；`Shift + 右键` 批量购买（每次翻倍）。

| 命令 | 功能 |
|------|------|
| `/qs create` | 创建商店（等价手持物品左键箱子） |
| `/qs price <金额>` | 修改价格（需 500 辻币） |
| `/qs remove` | 移除商店 |
| `/qs find <物品>` | 搜索全服出售该物品的商店 |
| `/qs staff` | 打开商店管理界面 |
| `/qs info` | 查看商店信息 |
| `/qs buy` / `/qs sell` | 切换商店模式（收购 / 出售） |

主城设有管理商店（木材/建筑/杂物），通过 `/cd` 进入，售价约为系统收购价的 2~3 倍。

## 粘液科技

Slimefun（粘液科技）让你在原版 Minecraft 中实现电力、自动化、多方块结构、特殊装备与魔法物品。

上手步骤：

1. 获取指南书：用一本书（Paper）右键，或输入 `/sf guide`。
2. 了解科技树：物品组按顺序解锁——石器时代 → 铁器时代 → 电力时代 → 高级科技。
3. 早期目标：合成「增强合成台」「多功能工具」→ 搭建「煤炭发电机」→ 连接「电力粉碎机」。

电力单位为 J（焦耳），核心组件：发电机（产电）、电容（储电）、电力机器（耗电）、连接器（输电）。基础方案：煤炭发电机 → 放入煤炭/木炭 → 电容储电 → 电力机器。

| 发电机 | 燃料 | 发电量 | 难度 |
|--------|------|--------|------|
| 煤炭发电机 | 煤炭、木炭 | 中 | 简单 |
| 生物质发电机 | 有机物 | 中 | 简单 |
| 太阳能发电机 | 阳光 | 低（白天） | 简单 |
| 风能发电机 | 风 | 波动 | 中等 |
| 地热发电机 | 岩浆 | 高 | 中等 |
| 核反应堆 | 铀 | 极高 | 困难 |

重要多方块结构：

| 多方块 | 功能 | 材料 |
|--------|------|------|
| 增强合成台 | 解锁高级合成 | 工作台 + 书架 × 4 |
| 压力机 | 压缩物品 | 活塞 + 石砖 |
| 冶炼炉 | 同时冶炼多个 | 熔炉 + 铁栏杆 |

常用命令：

| 命令 | 功能 |
|------|------|
| `/sf guide` | 打开指南书 |
| `/sf search <关键词>` | 搜索配方 |
| `/sf stats` | 查看统计 |
| `/sf researches` | 查看已解锁研究 |

注意：所有 Slimefun 机器必须放在岛屿保护范围内（距岛中心 50 格内）。自动保存已开启（每 10 分钟），离线时机器仍可运行。

## 箱子上锁

用 SignChestLock 给储物箱上锁（空岛内 BentoBox 已默认保护，此插件用于主城/公共区保护私人储物）。

上锁方法：手持木牌，对着箱子放置牌子，牌子首行写 `[Lock]`（或 `[Locked]`），第二行自动填你的名字；第 3 / 4 行写上信任玩家的名字，他们就能打开。只有所有者/被信任玩家能编辑或移除锁牌。

保护范围：他人无法打开/破坏；防爆炸、火焰、活塞推动；漏斗/漏矿车/投掷器不能抽放物品；比较器读出信号归零；支持双箱。

| 命令 | 功能 |
|------|------|
| `/signchestlock info` | 查看注视的锁定箱子信息 |
| `/signchestlock help` | 帮助 |

## 服务器规则

基本规则：

1. 禁止作弊：矿物追踪、非岛屿飞行、杀戮光环等作弊客户端/模组。
2. 禁止破坏他人财产。
3. 禁止恶意刷钱：利用漏洞刷币将清零并封禁。
4. 禁止刷屏。
5. 尊重他人：禁止辱骂、歧视、骚扰。
6. 禁止恶意 PVP：非 PVP 区域挑衅其他玩家。

建筑规则：不要在岛屿保护范围外建造永久建筑；不要建造影响性能的巨型红石机器；不要建造高空流水/岩浆装置（影响 TPS）。

商店规则：标价合理，禁止恶意哄抬/压价；确保商店有库存；禁止出售作弊物品或漏洞物品。

违规后果：

| 违规 | 后果 |
|------|------|
| 轻度 | 警告 + 禁言 |
| 中度 | 临时封禁（1~7 天） |
| 严重 | 永久封禁 |
| 利用漏洞 | 资产清零 + 永久封禁 |

## 常见问题 FAQ

**Q：为什么我进不去服务器？**
A：确认使用 Minecraft Java 版 26.2，且服务器在线、地址正确。

**Q：怎么注册/登录？**
A：首次 `/register <密码> <重复密码>`；后续 `/login <密码>`。忘记密码联系管理员或官方社群。

**Q：为什么我没有皮肤？**
A：服务器是离线模式，用 `/skin set <正版玩家名>` 设置，如 `/skin set Notch`。

**Q：怎么创建空岛？**
A：输入 `/is` 或 `/island`，系统自动生成专属空岛。

**Q：怎么和队友一起玩？**
A：队长输入 `/is team invite <玩家名>`，对方接受即可共同经营。

**Q：怎么赚钱？**
A：`/sign` 签到 → 砍树种田 → 卖资源 → 开玩家商店。

**Q：怎么提升岛屿等级？**
A：放置高价值方块，或用魔法刷石机产出稀有矿石。

**Q：Slimefun 机器怎么用？**
A：先做指南书（一本书右键）查看配方，从基础工具开始逐步解锁电力系统。

**Q：怎么去别人的岛？**
A：对方需在岛屿设置中开放传送，然后用 `/is warp <玩家名>` 传送。

**Q：被骚扰怎么办？**
A：用 `/is ban <玩家名>` 禁止对方进岛，情况严重联系管理员。

**Q：服务器卡顿怎么办？**
A：`/tps` 查看状态；大量掉落物时 `/lagg clear` 清理。
