Slimefun 2026.1 是 Minecraft 空岛服务器的科技玩法框架，在原生 Minecraft 中实现电力、自动化、多方块结构、特殊装备与魔法物品。本服已加载 3 个 Slimefun 附属，自动并入科技树。

Slimefun 是本服除空岛外最核心的进阶玩法：它让你从「手动合成」进化到「流水线自动化」，是岛屿后期发展与赚钱的关键。

## 快速上手

第一步，获取指南书：用一本书（Paper）在手里右键打开 Slimefun 指南书，或输入 `/sf guide`。如果还没有书，先用甘蔗做 3 张纸合成一本书。

第二步，了解科技树。Slimefun 的物品按物品组分类，需要逐步解锁（研究），整体脉络：

| 阶段 | 说明 |
|------|------|
| 石器时代 | 基础机器与工具，手动合成，不用电 |
| 铁器时代 | 增强机器、发电机，开始发电 |
| 电力时代 | 电力机器、电容，自动化生产 |
| 高级科技 | 多方块结构、编程，终极自动化 |

第三步，早期目标按顺序来：

1. 合成「增强合成台」，解锁更多合成配方。
2. 合成「多功能工具」，更高效的工具。
3. 搭建「煤炭发电机」，开始发电。
4. 连接「电力粉碎机」，双倍矿物产出。

## 电力系统详解

Slimefun 使用 J（焦耳）作为电力单位。核心组件：

| 组件 | 作用 |
|------|------|
| 发电机 | 生产电力 |
| 电容 | 储存电力 |
| 电力机器 | 消耗电力 |
| 连接器 | 传输电力 |

基础发电方案：煤炭发电机 → 放入煤炭/木炭 → 电能电容（储存）→ 电力机器（消耗）。

常见发电机：

| 发电机 | 燃料 | 发电量 | 难度 |
|--------|------|--------|------|
| 煤炭发电机 | 煤炭、木炭 | 中 | 简单 |
| 生物质发电机 | 有机物 | 中 | 简单 |
| 太阳能发电机 | 阳光 | 低（白天） | 简单 |
| 风能发电机 | 风 | 波动 | 中等 |
| 地热发电机 | 岩浆 | 高 | 中等 |
| 核反应堆 | 铀 | 极高 | 困难 |

## 与空岛的配合

- 所有 Slimefun 机器必须放在岛屿保护范围内（距岛中心 50 格内），否则会失去保护、可能被破坏，也不会被 BentoBox 识别。
- 若机器无法放置，检查是否超出了保护范围。
- 自动保存已开启：每 10 分钟自动保存一次。
- 离线时机器仍可继续运行。

若机器在岛屿内仍无法放置或运作，多半是位置已超出保护范围，请将机器移到岛屿中心区域内。

一条经典的自动化产线：刷石机 → 电力粉碎机 → 筛矿机 → 冶炼炉 → 成品箱。

## Slimefun 附属玩法

本服加载了 3 个附属插件，它们自动并入 `/sf guide` 的科技树，无需额外操作即会随研究进度解锁使用。

| 附属 | 玩法 | 说明 |
|------|------|------|
| ExoticGarden | 种植 / 烹饪 | 新增大量作物、果树与菜肴 |
| SlimefunWarfare | 军事 / 武器 | 枪械、武器、航天套装等军事向扩展 |
| SlimeHUD | 辅助显示 | 对准机器/物品时屏幕显示悬浮信息 |

### ExoticGarden（种植与烹饪）

大量新的果树与作物（橘子、桃子、樱桃、番茄、卷心菜、玉米、薯、辣椒等），可与空岛种植结合，提供丰富食材与特色产物。打破草方块时的种子/树苗掉落已全部开启，部分作物会从草丛中掉出。适合搭配耕种技能，实现多样化农庄。

入门玩法：在世界里找到三类可收集植物并右键收获——灌木丛（地上的树叶方块，如树莓）、带产物的植物（如番茄）、由原木加树叶加果实组成的果树（如椰子树）。烹饪的核心设施是「厨房」多方块结构：把配方材料放入发射器，再右键厨房上的活板门即可制作食物；果汁和冰沙可以放进小冰柜携带使用。进阶的魔法植物会产出魔法精华，积累后可合成各种资源。

详细配方与机制见 [ExoticGarden Wiki](https://slimefun-addons-wiki.guizhanss.cn/exotic-garden/getting-started)。

### SlimefunWarfare（军事与武器）

- 枪械：支持自动射击、可设置最小射程；子弹可从背包/副手使用。
- 爆炸物：混凝土有几率爆炸。
- 太空科技：陨石吸引器（可召唤含稀有金属的陨石）、航天套装等。
- 矿石：燧石等新矿石从石头掉落。

陨石相关参数：

| 项 | 值 |
|----|----|
| 陨石最小延迟 | 10 分钟 |
| 陨石最大延迟 | 30 分钟 |
| 吸引器冷却 | 1 分钟 |
| 陨石掉落半径 | 100（约 200×200 区域） |

### SlimeHUD（辅助显示）

对准机器/物品时，在 Boss 条显示该机器的实时信息。支持：机器进度、发电机发电量、电容储电量、货运/能源网络节点与通道数。可通过指令调整显示位置（bossbar / hotbar）。

## Slimefun 物品与经济

重要：Slimefun 物品不能卖给系统（不会出现在 `/sell` 收购表中）。因为机器可全自动生产大量物品，一旦可卖给系统会瞬间产生无限辻币，导致经济崩塌。

Slimefun 物品只能通过玩家商店（QuickShop）交易。因此，经营 Slimefun 产线、在玩家商店出售成品，是中后期赚钱的重要途径。

## 小贴士

1. 先熟悉基础合成，再逐步深入电力系统，避免一上来就被复杂科技树劝退。
2. 指南书随时随地右键即可查看配方，不需要靠近工作台。
3. 自动化产线尽量建在岛屿中心，并把成品或多余物品存入箱子，避免掉落物过多影响服务器性能（TPS）。
4. 善用 SlimeHUD 的实时信息，快速判断机器是否缺能源或卡住。
