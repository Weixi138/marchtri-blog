# 04 · 内容写作指南

## 1. 文章位置与命名

- 目录：`src/content/posts/`，文件名 = URL slug，建议英文/拼音短横线：`hello-sakura-mist.md`。
- 草稿：frontmatter `draft: true` 的文章构建时自动排除。

## 2. Frontmatter 规范

```yaml
---
title: 文章标题（必填）
published: 2026-08-29        # 发布日期（必填，用于热力图与排序）
description: 摘要，50–120 字，列表页与 SEO 用（建议必填）
tags: ["随笔", "建站"]        # 标签数组，2–5 个
category: 随笔               # 分类，单值；预置：随笔 / 技术 / 生活 / 折腾记录
draft: false                 # 可选，true = 草稿
pinned: false                # 可选，true = 置顶列表页
coverImage: /images/xxx.webp # 可选，封面（放 public/images/，建议 webp 1200×630）
music:                       # 可选，文末自动附玻璃播放卡
  file: /music/sakura.mp3    #   文件放 public/music/
  title: 曲目名
  artist: 作者
---
```

> 字段以 `src/content/config.ts` 的 schema 为准；schema 校验不通过 = 构建失败（这是有意设计，防止脏数据）。

## 3. 写作约定

- **语言**：正文中文；中英文之间加空格；标点用全角。
- **摘要**：`description` 认真写，它是首页与命令面板搜索的门面。
- **图片**：放 `public/images/`，Markdown 引用 `/images/xxx.webp`；宽度超过 800px 一律转 webp。
- **代码块**：标注语言（```ts）；行内代码用反引号。
- **音乐卡**：优先用 frontmatter `music` 字段（文末统一渲染），不建议正文里手动插。
- **长文**：用 `##` 二级标题分节，会自动生成目录。

## 4. 一言侧栏

「一言」卡片读 `src/data/hitokoto.json`（数组：`{ text, from }`），每次页面进入随机一条。想加自己的句子直接编辑该文件，**不依赖外部 API**。
