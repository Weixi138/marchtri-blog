# 01 · 产品与视觉设计规范

> 本文档是视觉与交互的**唯一权威标准**。任何 UI 改动以本文为准；改样式 = 改本文档 + 改 tokens.css，二者必须同步。

## 1. 站点定位

- **一句话**：一座会呼吸的玻璃花房——毛玻璃的优雅质感，装着日系可爱的心。
- **关键词**：柔软、通透、樱色、随四季/节气/天气/昼夜变化、有生命感。
- **目标**：访客停留 30 秒内能感受到「这个博客和别人不一样」。

## 2. 风格定义：毛玻璃优雅 × 日系可爱（融合）

| 维度 | 优雅侧（毛玻璃） | 可爱侧（日系） |
|---|---|---|
| 材质 | backdrop-blur 半透明层、细描边、柔影 | 圆角更大、微弹性动效 |
| 色彩 | 低饱和底色、大面积留白 | 樱花粉/淡紫点缀、暖橙强调 |
| 动效 | 平滑滚动、错落入场、视差 | 樱花飘落、点击绽放、打字机 |
| 字体 | 系统无衬线兜底 | LXGW 文楷（标题+正文） |

原则：**可爱做点缀，优雅做底色**。任何一屏，樱花元素面积 ≤ 15%，保证耐看不腻。

### 固定参数（两主题共用）

- 圆角阶梯（禁止散落任意圆角）：`--radius-btn: 12px` → `--radius-md: 16px` → `--radius-lg: 20px` → `--radius-card: 24px` → `--radius-pill: 999px`
- 布局：`--sidebar-width: 17.5rem`；`--float-panel-top: 5.25rem`；`--page-width`（由 constants.ts 的 `PAGE_WIDTH` 经 Layout.astro 注入）；导航高度 `--nav-height: 3.5rem` / 滚动收缩 `--nav-height-collapsed: 2.9rem`
- 伪终端：窗口圆点 `--term-red / --term-yellow / --term-green`
- 毛玻璃：`--blur-glass: 20px`，附加 `saturate(1.4)`；描边 1px + 内侧高光
- 阴影：卡片 `0 8px 32px rgba(190,120,160,.10)`（深色下为黑色 30%）
- 字体：`"LXGW WenKai GB Screen", "LXGW WenKai Screen", "PingFang SC", "Microsoft YaHei", sans-serif`；代码块保留等宽栈；基础字号 `clamp(0.9375rem, 0.85rem + 0.35vw, 1rem)`（移动 15px → 桌面 16px 平滑）
- 品牌渐变：标题/主按钮/进度条统一使用「樱花粉 → 淡紫（→ 暖橙）」渐变（`.gradient-text` / `.btn-primary-grad` / `--grad-primary`）
- 界面禁用 emoji：图标一律 SVG

## 4. 「樱之时空」签名体系（独特性来源）

背景随访客当地天气与昼夜变化是全站最强资产；签名体系将其升维为**四季 × 廿四节气 × 天气**的时空叙事，并把「花瓣」统一为微交互语言。

### 4.1 季节状态（SceneState）

`src/effects/weather.ts` 导出 `Season` 与纯前端节气表（24 节气按固定日期表近似计算，零网络请求）。`init.ts` 启动时写入 `<html data-season="spring|summer|autumn|winter">`，天气场景更新时同步。底部徽标文案为三段式「节气 · 降水 · 昼夜」（如「谷雨 · 小雨 · 夜」）。

### 4.2 季节 Token（tokens.css）

- `--season-tint`：签名微交互的季节色，按 `data-season` 覆写（春樱粉 / 夏青碧 / 秋暖橙 / 冬蓝紫；深色模式单独提亮）。未注入属性时回退 `var(--sakura)`。
- `--banner-blob-1`：Banner 光斑按季节覆写。
- `--sakura-icon`：五瓣樱花 SVG data-URI（mask 用），供 h2 bullet / 进度条花瓣复用。

### 4.3 四季 Banner（MainGridLayout.astro）

四幅全内联 SVG 常驻，CSS 按 `data-season` 切换（`.banner-season`），属性注入前默认春樱，无位图、颜色全部引用 `--banner-petal / -petal-soft / -core`：

| 季节 | 画面 |
|---|---|
| 春 | 樱花枝（五瓣椭圆花 × 4 + 花苞点） |
| 夏 | 枝上风铃（穹顶铃身 + 短册纸） |
| 秋 | 枫叶枝（五裂枫叶 × 4） |
| 冬 | 雪枝（六出雪花 × 4 + 枝头积雪点） |

### 4.4 花瓣微交互宪法（三件套）

全站交互反馈统一三件套，禁止散落裸 `hover:scale`：

1. **hover** = 樱色光晕：`.glass-hover-lift` 悬浮光晕用 `--season-tint`
2. **focus-visible** = 季节花环：`.focus-ring`（双层 box-shadow，内圈底色外圈 75% `--season-tint`），所有可聚焦控件必须携带
3. **click** = 现有 ripple + click-burst 粒子

活动态统一为**花瓣形竖标**（`.petal-marker` / 导航 `::before` / TOC active-indicator，`border-radius: 999px 6px 999px 6px` 塑形，渐变 `--season-tint → --murasaki`）。

### 4.5 签名排版细节

- 文章 `h2` 前缀五瓣樱花 bullet（markdown.css，mask 自 `--sakura-icon`，随 `--season-tint` 变色）
- 发布日期为「明信片邮戳」：虚线圆章、微倾 -1.6°、hover 回正（PostMeta.astro）
- 阅读进度条顶端跟随一片花瓣（`#reading-progress::after`，reduced-motion 下隐藏）

## 5. 动效设计原则

1. **统一调度**：全部 canvas 动画经 FXManager（见 docs/02）；DOM 动画只用 CSS transition/animation + IntersectionObserver。禁止组件私设 `setInterval` / 独立 `requestAnimationFrame`。
2. **时长节奏**：微交互 150–250ms；入场 400–600ms；场景切换 ≥ 800ms。
3. **缓动**：入场用 `cubic-bezier(.22,1,.36,1)`；弹性用 `cubic-bezier(.34,1.56,.64,1)`；禁止 linear 长动画。
4. **编排**：列表入场按 60ms 错落（stagger）；同屏动画类型 ≤ 3 种。
5. **可关可降**：每个特效有开关（config.ts / 命令面板）；`prefers-reduced-motion` 用户看到的是「静态但完整」的页面——全部签名元素（樱花 bullet、邮戳、四季 Banner、焦点环）在静态下依然可见可用。

## 6. 版式与布局

- 首页：Hero 个人卡（头像/打字机简介/社交）+ 文章流；侧栏挂件位于内容**右侧**（移动端沉底），含精简身份卡与「一言」。
- Banner：**纯 CSS 渐变装饰**（`--grad-banner` 半透明叠加在天气天空 canvas 之上，含光斑与四季枝条剪影，底部渐隐进天空），首页约 52vh、内页约 32vh；不使用外链图片。
- 内容列宽 `max-width: 75ch`；移动端断点 768px。
- 导航：**顶部悬浮玻璃条**（固定顶部、滚动收缩），当前页季节色高亮 + 花瓣竖标；窄屏文字链接收进汉堡下拉菜单。
- 页脚：全布局**唯一** Footer（桌面跨主栏+侧栏两列，移动端单列），随 swup 常驻。

## 7. 验收标准（视觉）

- [ ] 深浅两主题下，对比度均达 WCAG AA（正文 ≥ 4.5:1）
- [ ] 樱花/粒子元素不遮挡正文阅读，鼠标 hover 卡片有弹性反馈
- [ ] 动效在 `prefers-reduced-motion` 下全部静止且页面完整
- [ ] 375px / 768px / 1440px 三档宽度无横向滚动、无布局破碎
- [ ] 字体加载期间无 FOIT 超过 100ms（`font-display: swap`）
- [ ] 四季 Banner 与 `--season-tint` 微交互在 mock 日期（四季 + 节气边界）下渲染正确
- [ ] 组件内无硬编码色值（grep 断言：组件内不出现 `rgba(255,255,255` 与 `oklch(`）
