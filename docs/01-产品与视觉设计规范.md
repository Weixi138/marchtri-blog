# 01 · 产品与视觉设计规范

> 本文档是视觉与交互的**唯一权威标准**。任何 UI 改动以本文为准；改样式 = 改本文档 + 改 tokens.css，二者必须同步。

## 1. 站点定位

- **一句话**：一座会呼吸的玻璃花房——毛玻璃的优雅质感，装着日系可爱的心。
- **关键词**：柔软、通透、樱色、随昼夜与天气变化、有生命感。
- **目标**：访客停留 30 秒内能感受到「这个博客和别人不一样」。

## 2. 风格定义：毛玻璃优雅 × 日系可爱（融合）

| 维度 | 优雅侧（毛玻璃） | 可爱侧（日系） |
|---|---|---|
| 材质 | backdrop-blur 半透明层、细描边、柔影 | 圆角更大、微弹性动效 |
| 色彩 | 低饱和底色、大面积留白 | 樱花粉/淡紫点缀、暖橙强调 |
| 动效 | 平滑滚动、错落入场、视差 | 樱花飘落、点击绽放、打字机 |
| 字体 | 系统无衬线兜底 | LXGW 文楷（标题+正文） |

原则：**可爱做点缀，优雅做底色**。任何一屏，樱花元素面积 ≤ 15%，保证耐看不腻。

## 3. 色彩 Token（src/styles/tokens.css）

### 固定参数（两主题共用）

- 圆角：卡片 `--radius-card: 24px`；按钮/输入 `--radius-btn: 12px`；导航/播放器胶囊 `--radius-pill: 999px`
- 毛玻璃：`--blur-glass: 20px`，附加 `saturate(1.4)`；描边 1px + 内侧高光
- 阴影：卡片 `0 8px 32px rgba(190,120,160,.10)`（深色下为黑色 30%）
- 字体：`"LXGW WenKai GB Screen", "LXGW WenKai Screen", "PingFang SC", "Microsoft YaHei", sans-serif`；代码块保留等宽栈
- 品牌渐变：标题/主按钮/进度条统一使用「樱花粉 → 淡紫（→ 暖橙）」渐变（`.gradient-text` / `.btn-primary-grad` / `--grad-primary`）
- 界面禁用 emoji：图标一律 SVG

## 4. 动效设计原则

1. **统一调度**：全部 canvas 动画经 FXManager（见 docs/02）；DOM 动画只用 CSS transition/animation + IntersectionObserver。
2. **时长节奏**：微交互 150–250ms；入场 400–600ms；场景切换 ≥ 800ms。
3. **缓动**：入场用 `cubic-bezier(.22,1,.36,1)`；弹性用 `cubic-bezier(.34,1.56,.64,1)`；禁止 linear 长动画。
4. **编排**：列表入场按 60ms 错落（stagger）；同屏动画类型 ≤ 3 种。
5. **可关可降**：每个特效有开关（config.ts / 命令面板）；`prefers-reduced-motion` 用户看到的是「静态但完整」的页面。

## 5. 版式与布局

- 首页：Hero 个人卡（头像/打字机简介/社交）+ 文章流；侧栏挂件位于内容**右侧**（移动端沉底），含精简身份卡与「一言」。
- Banner：**纯 CSS 渐变装饰**（`--grad-banner` 半透明叠加在天气天空 canvas 之上，含光斑与樱花枝剪影，底部渐隐进天空），首页约 52vh、内页约 32vh；不使用外链图片。
- 内容列宽 `max-width: 75ch`；移动端断点 768px。
- 导航：**顶部悬浮玻璃条**（`--radius-pill` 胶囊、固定顶部居中），滚动时收缩高度（`--nav-height` → `--nav-height-collapsed`）；当前页樱粉高亮；窄屏文字链接收进汉堡下拉菜单。

## 6. 验收标准（视觉）

- [ ] 深浅两主题下，对比度均达 WCAG AA（正文 ≥ 4.5:1）
- [ ] 樱花/粒子元素不遮挡正文阅读，鼠标 hover 卡片有弹性反馈
- [ ] 动效在 `prefers-reduced-motion` 下全部静止且页面完整
- [ ] 375px / 768px / 1440px 三档宽度无横向滚动、无布局破碎
- [ ] 字体加载期间无 FOIT 超过 100ms（`font-display: swap`）
