# 03 · 功能需求清单

> 优先级：**P0 = 基础必需**，**P1 = 特色功能**。每项含验收标准；实现与本文不符 = 未完成。

## P0 · 基础

### P0-1 主题视觉
粉紫色板（docs/01）+ 毛玻璃组件体系（导航/卡片/侧栏/弹层）+ LXGW 文楷。深浅主题一键切换并记忆。
**验收**：任意页面切主题无闪烁（无 FOUC）；玻璃质感在纯色壁纸下依然可见描边。

### P0-2 动态特效包
- Hero 打字机副标题（循环轮播多句文案，光标闪烁）
- 滚动入场编排（卡片错落浮现，60ms stagger）
- 页面转场（Fuwari 内置 swup，前进淡入推入、后退滑出）
- 樱花飘落层（≤ 24 朵，微风摆动，可开关）
- 点击绽放粒子（樱花瓣 + 星点，每次 ≤ 12 粒，节流 200ms）
**验收**：全部接入 FXManager；移动端密度减半；reduced-motion 静态。

### P0-3 内容骨架
文章/分类/标签/归档/RSS/sitemap/搜索（命令面板承载）。「一言」侧栏卡（本地句子库随机）。

### P0-4 giscus 评论（`features.comments`）
文章底部。`config.comments` 未配置 repo 时渲染占位提示文案，不报错。

### P0-5 强制加载动画（`features.loadingScreen`）
每次整页加载强制显示 3 秒：樱花 SVG 绽放 + 渐变标题 + 进度条走满后淡出。视觉退场由纯 CSS `animation-delay: 3s` 保证（无 JS 也准时）；JS 仅负责移除节点（3.5s / 4.5s 双保险）。reduced-motion 下省略装饰动画但保留 3s 时长。

### P0-6 鼠标跟随光晕 + 点击涟漪（`features.cursorGlow`）
桌面端（coarse pointer / reduced-motion 跳过）：柔光斑以插值跟随指针；每次点击生成一圈渐隐涟漪。

## P1 · 五大特色功能

### P1-1 命令面板 + 伪终端（`features.commandPalette` / `features.terminal`）

**命令面板**：`Ctrl+K` / `Cmd+K` 唤起，毛玻璃弹层（bg-glass-strong）。
- 内容：文章标题/摘要模糊搜索 + 页面跳转（首页/归档/看板/关于）+ 动作（切换主题、开关樱花/粒子/天气背景、复制 RSS 链接）。
- 交互：方向键导航、Enter 执行、Esc 关闭、空输入显示最近文章。

**伪终端**：按 `` ` ``（反引号）唤起，等宽字体的玻璃窗。
- 命令：`help`（列出命令）、`ls`（列出文章：序号+日期+标题）、`read <序号|关键词>`（跳转正文）、`theme light|dark|auto`、`cd about|archive|dashboard`（跳页）、`clear`、`exit`、未知命令输出卖萌提示。
- 细节：支持 ↑ 历史、Tab 补全命令名；打开时 focus 输入框。

**验收**：面板/终端首次按键后 300ms 内可交互（惰性分包）；两处唤起互不冲突；移动端提供导航栏按钮入口。

### P1-2 天气×昼夜动态背景（`features.weatherBg`）

- 数据：Open-Meteo `current_weather`（免 key）；定位：`navigator.geolocation`（可选），拒绝/失败 → IP 粗定位（CF 请求头 `cf-ipcity` 级别的经纬度不可用则跳过）→ 降级为纯时间模式。30 分钟 localStorage 缓存。
- 昼夜底色（canvas 渐变）：黎明 5–7 樱橙 → 白天 7–17 淡青樱 → 黄昏 17–19 暖紫橙 → 夜晚 19–5 深紫星空。随时间平滑过渡。
- 天气粒子层：`weather_code` 映射——雨/阵雨→雨丝斜落，雪→雪花飘落，雾→流动薄雾带，雷→偶发闪白，晴/多云→浮光斑。夜间晴天叠加星星闪烁。
- 交互：命令面板可开关；页面底部小徽标显示当前场景（如「☁ 多云 · 黄昏」）。

**验收**：断网/接口失败无感知降级；手动切主题时背景自适应不撕裂；粒子不遮挡正文。

### P1-3 音乐播放器 + 音频律动（`features.musicPlayer`）

- **网易云模式（默认）**：`config.music.neteasePlaylistId` 填入歌单 ID 时，悬浮玻璃面板内嵌网易云官方外链播放器（iframe）。跨域限制下无法做频谱律动，这是浏览器硬限制。
- **本地模式（备用）**：歌单 ID 留空时使用 `public/music/` 本地曲库；播放时经 Web Audio `AnalyserNode` 取低频能量驱动背景光晕呼吸，文章内可嵌入播放卡（frontmatter `music` 字段）。
- 右下角唱片胶囊：网易云模式面板展开时缓转；本地模式播放时旋转。**不自动播放本地音频**；音量与曲目记忆 localStorage。

**验收**：网易云 iframe 正常加载歌单；本地模式后台标签页暂停不报错；移动端可收起为小按钮不挡内容。

### P1-5 写作热力图 + 数据看板（`features.dashboard`）

- `/dashboard` 页，数据由构建期 `scripts/scan-stats.mjs` 从 content collections 生成：
  - GitHub 式写作热力图（近 52 周，按 `published` 日期计数，五档樱粉色阶）
  - 统计卡：文章数 / 总字数 / 分类数 / 标签数 / 最长连续写作周
  - 分类分布条形图（CSS 实现，无图表库）+ 年度写作卡片（今年 N 篇 × M 字）
**验收**：零文章时页面显示空状态插画文案；数据全部构建期生成，运行时零请求。
