# 03 · 功能需求清单

> 优先级：**P0 = 基础必需**，**P1 = 特色功能**。每项含验收标准；实现与本文不符 = 未完成。

## P0 · 基础

### P0-1 主题视觉
粉紫色板（docs/01）+ 毛玻璃组件体系（导航/卡片/侧栏/弹层）+ LXGW 文楷。深浅主题一键切换并记忆。
**验收**：任意页面切主题无闪烁（无 FOUC）；玻璃质感在纯色壁纸下依然可见描边。

### P0-2 动态特效包
- Hero 打字机副标题（循环轮播多句文案，光标闪烁）
- 滚动入场编排（卡片错落浮现，60ms stagger）
- 页面转场（Fuwari 内置 swup，前进淡入推入、后退滑出）
- 四季粒子层（随 data-season 切换：春樱瓣 ≤24 朵 / 夏夜萤火 / 秋枫叶 / 冬细雪；移动端减半，微风摆动，可开关）
- 点击绽放粒子（樱花瓣 + 星点，每次 ≤ 12 粒，节流 200ms）
**验收**：全部接入 FXManager；移动端密度减半；reduced-motion 静态；低内存设备（deviceMemory ≤ 4 / saveData）自动关闭全部粒子层。

### P0-3 内容骨架
文章/分类/标签/归档/RSS/sitemap/搜索（命令面板承载）。「一言」侧栏卡（本地句子库随机）。

### P0-4 giscus 评论（`features.comments`）
文章底部。`config.comments` 已配置 repo/repoId/categoryId（Weixi138/marchtri-blog）。未配置时渲染占位提示文案，不报错。

### P0-5 加载动画（`features.loadingScreen`，可跳过）
每次整页加载显示：樱花 SVG 绽放 + 渐变标题 + 进度条。退场策略：**最短展示 1.2s**（保证开场动画完整）→ 资源就绪（`load` / `readyState complete`）提前退场 → **3.5s 上限**兜底；期间任意**点击或按键**立即跳过；退场走 `.fx-loader-out` 淡出后移除节点。reduced-motion 下近瞬退场（约 300ms）。
**验收**：慢网络下不超过 3.5s；用户主动点击/按键即刻进入页面；reduced-motion 用户几乎无感；无 JS 报错残留遮罩。

### P0-6 鼠标跟随光晕 + 点击涟漪（`features.cursorGlow`）
桌面端（coarse pointer / reduced-motion 跳过）：柔光斑以插值跟随指针；每次点击生成一圈渐隐涟漪。

## P1 · 特色功能

### P1-1 命令面板 + 伪终端（`features.commandPalette` / `features.terminal`）

**命令面板**：`Ctrl+K` / `Cmd+K` 唤起，毛玻璃弹层（bg-glass-strong）。
- 内容：文章标题/摘要模糊搜索 + 页面跳转（首页/归档/看板/照片/关于）+ 动作（切换主题、开关樱花/粒子/天气背景、复制 RSS 链接）。
- 交互：方向键导航、Enter 执行、Esc 关闭、空输入显示最近文章。

**伪终端**：按 `` ` ``（反引号）唤起，等宽字体的玻璃窗。
- 命令：`help`（列出命令）、`ls`（列出文章：序号+日期+标题）、`read <序号|关键词>`（跳转正文）、`theme light|dark|auto`、`cd about|archive|dashboard|photos`（跳页）、`clear`、`exit`、未知命令输出卖萌提示。
- 细节：支持 ↑ 历史、Tab 补全命令名；打开时 focus 输入框。

**验收**：面板/终端首次按键后 300ms 内可交互（惰性分包）；两处唤起互不冲突；移动端提供导航栏按钮入口。

### P1-2 天气×昼夜×四季动态背景（`features.weatherBg`，「樱之时空」第一签名）

- 数据：Open-Meteo `current_weather`（免 key）；定位：`navigator.geolocation`（可选），拒绝/失败 → IP 粗定位 → 降级为纯时间模式。30 分钟 localStorage 缓存；轮询经三重门控（页面可见 && 开关开启或时段跨越），天气关闭时零网络请求。
- 昼夜底色（canvas 渐变）：黎明 5–7 樱橙 → 白天 7–17 淡青樱 → 黄昏 17–19 暖紫橙 → 夜晚 19–5 深紫星空。随时间平滑过渡。
- **季节维度**：季节按月份纯前端计算、节气按固定日期表近似（零网络请求），写入 `<html data-season>`；天空色板按季节微染 10%（春樱粉/夏青碧/秋暖橙/冬蓝紫），Banner 与全站微交互色（`--season-tint`）随之切换（规范见 docs/01 §4）。
- 天气粒子层：`weather_code` 映射——雨/阵雨→雨丝斜落，雪→雪花飘落，雾→流动薄雾带，雷→偶发闪白，晴/多云→浮光斑。夜间晴天叠加星星闪烁。
- 交互：命令面板可开关；页面底部小徽标显示三段式场景「节气 · 降水 · 昼夜」（`aria-live="polite"`）。

**验收**：断网/接口失败无感知降级；手动切主题时背景自适应不撕裂；粒子不遮挡正文；mock 日期覆盖四季与节气边界时场景与徽标文案正确。

### P1-3 音乐播放器 + 音频律动（`features.musicPlayer`）

- **网易云模式（默认）**：`config.music.neteasePlaylistId` 填入歌单 ID 时，悬浮玻璃面板内嵌网易云官方外链播放器（iframe）。跨域限制下无法做频谱律动。
- **本地模式（备用）**：歌单 ID 留空时使用 `public/music/` 本地曲库；播放时经 Web Audio `AnalyserNode` 取低频能量驱动背景光晕呼吸。
- 右下角唱片胶囊：网易云模式面板展开时缓转；本地模式播放时旋转。**不自动播放本地音频**；音量与曲目记忆 localStorage。

**验收**：网易云 iframe 正常加载歌单；本地模式后台标签页暂停不报错；移动端可收起为小按钮不挡内容。

### P1-5 写作热力图 + 数据看板（`features.dashboard`）

- `/dashboard` 页，数据全部构建期生成，运行时零请求：
  - GitHub 式写作热力图（近 52 周，按 `published` 日期计数，五档樱粉色阶）
  - 统计卡：文章数 / 总字数 / 分类数 / 标签数 / 最长连续写作周
  - 分类分布条形图（CSS 实现，无图表库）+ 年度写作卡片

**验收**：零文章时页面显示空状态插画文案。

### P1-6 照片墙（`features.photoWall`）

- `/photos` 页，CSS Grid 响应式瀑布流：
  - 桌面 3 列 / 平板 2 列 / 手机 1 列
  - 照片数据来自 `src/data/photos.json`（构建期静态，运行时零请求）
  - 点击弹出 PhotoSwipe 全屏灯箱（项目已引入 photoswipe）
  - 毛玻璃卡片容器 + `.glass-hover-lift` hover 上浮效果
  - 每张照片支持可选 caption（hover 时渐显）
- 导航栏、命令面板、伪终端均已接入照片页入口。
- 空数据时显示占位提示。

**验收**：照片加载不阻塞首屏；移动端可正常浏览；灯箱操作流畅。

### P1-7 开发者工具防护（`features.devGuard`）

- 禁用右键菜单 + 拦截 F12 / Ctrl+Shift+I / Ctrl+Shift+J / Ctrl+U 等 DevTools 快捷键
- 触发时自动跳转 `https://www.baidu.com`
- 仅拦截表层操作，专业用户仍可通过地址栏 `view-source:` 等方式绕过
- 默认关闭（`devGuard: false`），可在 config.ts 中开启

**验收**：右键无菜单；快捷键触发跳转百度；不影响正常浏览。

### P1-8 博客后台：登录与在线发文（`featureConfig.adminPanel`）

- 入口 `/admin/`（不进导航，直接访问）。密码登录：密码以 secret 加密存于 Cloudflare + 恒定时间比对（HMAC 签名 session cookie，7 天，HttpOnly/SameSite=Lax，5 次失败锁 15 分钟）。不用 KDF 哈希——Workers 免费版 CPU 限制会击杀 PBKDF2（见 docs/05）。
- 功能：文章列表 / 新建 / 编辑 / 删除。正文经 Worker 用 GitHub Contents API 提交为仓库 commit（文件名白名单 + frontmatter 必备字段校验），push 触发自动构建，约 1-2 分钟上线；文章始终留在 git。
- 编辑器：textarea + markdown-it 分栏预览（html:false），毛玻璃风格，零新增依赖。
- 部署与 secrets 配置见 docs/05；`adminPanel: false` 时 /admin 返回 404（API 仍受密码保护）。

**验收**：错密 401、篡改 cookie 401、非 JSON 请求 415；发文在 GitHub 产生正确 commit 并如期上线；非法文件名 / 缺 title 被 400 拒绝；sha 冲突 409 有中文提示。
