# 05 · 部署指南（Cloudflare Pages）

站点为纯静态产物，两种路线任选其一。

## 前置

```bash
pnpm install
pnpm build          # 确认零报错，产物在 dist/
```

## 路线 A · wrangler 直部（最快）

```bash
npx wrangler login                    # 首次：拉起浏览器授权 Cloudflare
npx wrangler pages project create sakura-mist   # 项目名自定，仅需一次
npx wrangler pages deploy dist --project-name=sakura-mist
```

输出 `*.pages.dev` 域名即上线。以后每次更新：`pnpm build && npx wrangler pages deploy dist`。
（本仓库提供 `scripts/deploy.mjs` 封装上述两步。）

## 路线 B · GitHub + 自动构建（推荐长期，已采用）

仓库：<https://github.com/Weixi138/marchtri-blog>

1. 推送即部署的前置：Cloudflare Pages 连接一次该仓库。
2. Cloudflare 控制台 → Workers & Pages → Create → Pages → 连接该仓库。
3. 构建设置：
   - Framework preset: **Astro**
   - Build command: `pnpm build`
   - Build output directory: `dist`
   - 环境变量：`NODE_VERSION` = `22`
4. 保存后每次 `git push` 自动部署；PR 生成预览链接。

## 自定义域名

Pages 项目 → Custom domains → 添加域名，按提示在域名服务商加 CNAME 到 `<project>.pages.dev`。

## 缓存策略

`public/_headers` 已配置：带 hash 的 `_astro/*` 资源 `immutable`，HTML `no-cache`，字体 `max-age=31536000`。

## 常见问题

- **构建内存不足**：Cloudflare 免费版 3GB 内存，Astro 默认足够；若卡在图片处理，减少 `coverImage` 原图体积。
- **文楷字体首包大**：已按 unicode-range 分包，只需确认不要把 `lxgw-wenkai` 的整包 ttf 复制进 `public/`。
- **天气接口**：Open-Meteo 免费无 key，浏览器端直连；国内网络偶发慢，属正常，会静默降级为昼夜模式。
- **网易云播放器空白**：检查 `musicConfig.neteasePlaylistId` 是否为有效歌单 ID；歌单需为公开状态。
