# 02 · 技术架构与性能预算

## 1. 架构总览

```
┌────────────────────────── 浏览器 ──────────────────────────┐
│  Astro 静态页 (SSG)                                        │
│  ├─ 结构层: Astro 组件 (零运行时)                           │

│  └─ 特效层: FXManager (单 rAF)                              │
│      ├─ dynamic-bg   天气×昼夜动态背景 (canvas)             │
│      ├─ sakura       樱花飘落层 (canvas)                    │
│      ├─ click-burst  点击绽放粒子 (canvas)                  │
│      ├─ cursor-glow  鼠标跟随光晕 + 点击涟漪 (DOM)          │

│  开屏: LoadingScreen 强制 3s 加载动画 (纯 CSS 退场保底)     │
└────────────────────────────────────────────────────────────┘
        │ 构建期                              │ 运行期(可选)
        ▼                                     ▼
  文章扫描→热力图/看板数据             Open-Meteo 天气(30min缓存)
                                       Geolocation(拒绝则降级)
```

- **渲染策略**：全部 SSG 静态页；JS 只存在于交互岛与特效层。
- **内容引擎**：Fuwari 的 content collections / 分类 / 标签 / RSS / sitemap / 暗色切换原样保留；视觉层组件全部重写。

## 2. FXManager 设计（src/effects/manager.ts）

```ts
interface FXLayer {
  name: string;
  visible: boolean;               // 视口内才 tick
  tick(dt: number, t: number): void;
  resize(w: number, h: number): void;
  staticFrame?(): void;           // reduced-motion 时画一次
}
```

- 单一 `requestAnimationFrame` 循环，`dt` 驱动，所有层共享一个 `<canvas>` 栈（背景层 1 个 + 粒子层 1 个，避免多 canvas 叠加）。
- `document.visibilitychange` → 暂停/恢复；`IntersectionObserver` 决定粒子层是否 tick。
- DPR 上限 2（移动端 1.5），防止高分屏过绘。
- `prefers-reduced-motion` → 只调各层 `staticFrame()` 一次。

### 降级矩阵

| 条件 | 行为 |
|---|---|
| `prefers-reduced-motion` | 全部静态帧，无循环动画 |
| 移动端（宽 < 768 或 coarse pointer） | 樱花密度 ×0.5、粒子减半、DPR ≤1.5 |
| `navigator.deviceMemory ≤ 4` 或 `saveData` | 关闭 dynamic-bg 粒子层，只保留渐变底色 |
| Web Audio 不可用 / 未播放 | 律动层输出静止光晕 |

## 3. 页面与数据流

| 路由 | 内容 | 运行时依赖 |
|---|---|---|
| `/` | Hero + 文章流 | FXManager、天气、打字机、鼠标光晕 |
| `/posts/[slug]` | 正文 + 阅读进度条 + giscus | FXManager、播放卡片 |

构建期数据采集直接在页面 frontmatter 中完成（`dashboard.astro` 在页面 frontmatter 中扫描统计），`scripts/` 保留 `gen-music.mjs`（占位音频合成）与 `deploy.mjs`（一键部署）。

## 4. 性能预算（硬性）

| 指标 | 预算 |
|---|---|
| 首屏 JS（gzip，首页） | ≤ 100KB（含特效层与命令面板惰性分包前） |
| 首屏 JS（gzip，文章页） | ≤ 70KB |
| Canvas 帧率 | 60fps（桌面）/ ≥ 50fps（中端手机） |
| 单帧主线程占用 | ≤ 4ms |
| 字体 | 文楷仅 unicode-range 分包子集 + `swap`；首屏字体请求 ≤ 8 个 |
| 图片 | 封面一律 `<Image>` 生成 webp，宽高必填防 CLS |
| Lighthouse | 性能：移动 ≥ 80 / 桌面 ≥ 95；可访问性 ≥ 90；SEO ≥ 95 |

## 5. 构建与部署产物

- `pnpm build` → `dist/` 纯静态。
- Cloudflare Pages：构建命令 `pnpm build`，输出 `dist`，`NODE_VERSION = 22`。
- 静态资源 Cache-Control：`public/_headers`（带 hash 资源 immutable，HTML no-cache）。

## 6. 关键实现约定

- 所有交互岛**惰性加载**（`client:idle` 或 `client:visible`），命令面板与终端只在首次按键时拉取 JS。
- 天气数据：`localStorage` 缓存 30 分钟；请求失败静默降级为「纯昼夜模式」，不弹错误。
- 音乐播放器：网易云官方外链 iframe（歌单 ID 在 config 配置）为默认；本地曲库备用模式走 `<audio>` + AnalyserNode 律动；本地音频不自动播放，音量记忆 localStorage。
- giscus 未配置时（config 为空）文章页不渲染任何评论 DOM，不报错。
