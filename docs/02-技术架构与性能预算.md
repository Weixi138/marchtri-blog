# 02 · 技术架构与性能预算

## 1. 架构总览

```
┌────────────────────────── 浏览器 ──────────────────────────┐
│  Astro 静态页 (SSG)                                        │

        ▼                                     ▼
```

- **渲染策略**：全部 SSG 静态页；JS 只存在于交互岛与特效层。
- **内容引擎**：Fuwari 的 content collections / 分类 / 标签 / RSS / sitemap / 暗色切换原样保留；视觉层组件全部重写。

## 2. FXManager 设计（src/effects/）

```ts
interface FXLayer {
  name: string;
  tick(dt: number, t: number): void;
  resize(w: number, h: number): void;
  staticFrame?(): void;           // reduced-motion 时画一次
}
```

- **单一 `requestAnimationFrame` 循环**，全站唯一动画心跳；`dt` 钳制防止后台切换回来时跳帧。
- **单一 `<canvas id="fx-canvas">`**：sky / sakura / click-burst 各为一个绘制阶段，按顺序画在同一画布上；无多 canvas 叠加，无 IntersectionObserver 门控（画布本身 `position: fixed` 常驻，滚出视口的概念不适用）。
- **`addSampler(cb)`**：任何需要每帧采样的逻辑（如音乐能量）注册进单循环，禁止组件自持 rAF；`fxState.audioEnergy` 是能量唯一数据源。
- **生命周期**：`visibilitychange` → 暂停/恢复；`resize` → 各层重设尺寸；两个监听器在 `destroy()` 中显式移除，`initFX()` 返回 dispose（清理轮询定时器 + 全局监听 + `window.__fxManager`），swup 多次跳转后无累积泄漏。
- DPR 上限 2（移动端 1.5），防止高分屏过绘。
- `prefers-reduced-motion` → 只调各层 `staticFrame()` 一次。

### 「樱之时空」场景状态（weather.ts / sky.ts）

- `SceneState = { period, precip, label, season, solarTerm }`；季节按月份纯前端计算，节气按固定日期表近似（24 条，零网络请求）。
- `init.ts` 写入 `<html data-season>`，tokens.css 季节覆写（`--season-tint` 等）由此生效（见 docs/01 §4）。
- sky 层色板 = 昼夜时段基色板 × 季节微染（`SEASON_TINT` 按 10% 混合）；场景切换时重算一次，不逐帧计算。
- 性能细节：深色模式经 `MutationObserver` 缓存布尔值；一天中的时间分数缓存 60s；均不逐帧读 DOM / new Date()。

### 天气轮询与网络

- 单一定时器（10 分钟）三重门控：`!document.hidden` 且（天气开关开启 或 昼夜时段跨越）。
- `fetchScene` 内置 30 分钟 localStorage 缓存，命中缓存的轮询不发请求；接口失败静默降级为纯时间模式。
- 天气关闭时除时段跨越（走无网络回退场景）外，零网络请求。

### 降级矩阵

| 条件 | 行为 |
|---|---|
| `prefers-reduced-motion` | 全部静态帧，无循环动画；LoadingScreen 近瞬退场 |
| 移动端（宽 < 768 或 coarse pointer） | 樱花密度 ×0.5、粒子减半、DPR ≤1.5 |
| `navigator.deviceMemory ≤ 4` 或 `saveData` | initFX 自动检测，关闭全部粒子层（sakura/clickBurst/weatherBg），只保留渐变底色 |
| Web Audio 不可用 / 未播放 | 采样器输出能量 0，律动静止 |

## 4. 性能预算（硬性）

| 指标 | 预算 |
|---|---|
| 首屏 JS（gzip，首页） | ≤ 100KB（含特效层与命令面板惰性分包前） |
| 首屏 JS（gzip，文章页） | ≤ 70KB |
| 活跃 rAF 循环 | 全站任意时刻 ≤ 1 条（FXManager） |
| Canvas 帧率 | 60fps（桌面）/ ≥ 50fps（中端手机） |
| 单帧主线程占用 | ≤ 4ms |
| 字体 | 文楷仅 unicode-range 分包子集 + `swap`；首屏字体请求 ≤ 8 个 |
| 图片 | 封面一律 `<Image>` 生成 webp，宽高必填防 CLS |
| Lighthouse | 性能：移动 ≥ 80 / 桌面 ≥ 95；可访问性 ≥ 90；SEO ≥ 95 |

## 5. 构建与部署产物

- `pnpm build` → `dist/` 纯静态。
- Cloudflare Pages：构建命令 `pnpm build`，输出 `dist`，`NODE_VERSION = 22`。
- 静态资源 Cache-Control：`public/_headers`（带 hash 资源 immutable，HTML no-cache）。

## 6. 关键实现约定

- 所有交互岛**惰性加载**（`client:idle` 或 `client:visible`），命令面板与终端只在首次按键时拉取 JS。
- 天气数据：`localStorage` 缓存 30 分钟；请求失败静默降级为「纯昼夜模式」，不弹错误。
- 音乐播放器：网易云官方外链 iframe（歌单 ID 在 config 配置）为默认；本地曲库备用模式走 `<audio>` + AnalyserNode，能量经 `addSampler` 并入单循环；本地音频不自动播放，音量记忆 localStorage。
- LoadingScreen：最短展示 1.2s（保证开场动画完整）→ 资源就绪提前退场 → 3.5s 上限兜底；点击/按键可跳过；reduced-motion 近瞬退场。
- giscus 未配置时（config 为空）文章页不渲染任何评论 DOM，不报错。
