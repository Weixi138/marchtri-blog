# 樱雾小筑 v2 改造方案（MarchTri 专属版）

## 你点名的 8 项

### 1. 全站去 Emoji（1）
所有界面文案里的 emoji 清除，按场景替换为：
- 界面图标 → 站内 SVG 图标（iconify / 自绘樱花 SVG），不再用字符表情
- 404 大花 → 用本站樱花 favicon SVG 渲染
- 终端 neofetch → 纯 ASCII 字符画
- 保留极少数非 emoji 符号：`⌘`（命令符号）、`❯`（终端提示符）、`↑↓↵`（快捷键提示）

### 2. 配色与 UI 去模板化（2）
- 标题系统：Hero 标题 / 各页大标题 / 文章标题竖条改为「樱花粉→淡紫」渐变字与渐变条
- 卡片 hover：加辉光描边（粉紫光晕），不再是单纯上浮
- 导航站名改渐变文字；主按钮渐变底
- 深色底色调成更独特的深李紫（非通用紫黑），卡片描边加深保证玻璃质感
- 圆角加大一档（20→24px），加强「软糯」感

### 3–5. 个人信息（3/4/5/6）
- 站点作者：**MarchTri**（页脚、侧栏、Hero 问候语、OG 信息全部同步）

### 7. 示例内容重写（6/7）
- 3 篇示例文章 + 关于页全部以 MarchTri 口吻重写，去除 emoji、去除「示例/演示」腔
- 一言库微调；Hero 问候语与打字机文案同步更新

### 8. 移除追番页（8）
- 删除 `/bangumi` 路由、导航入口、命令面板入口、终端 `cd bangumi`、配置项与缓存文件
- docs/AGENTS.md 同步更新（功能清单标记移除原因：Bangumi 接口不可用）

### 9. 强制 3 秒加载动画（9）
- 每次整页加载都显示（纯 CSS 动画保证无 JS 也准时退场，不闪内容）：
  深李紫幕布 + 樱花 SVG 逐瓣绽放 + 渐变进度条 3s 走满 + 淡出
- `config.ts` 开关 `loadingScreen`（默认开）

### 10. 音乐改网易云（10）
- 播放器改为**网易云官方外链播放器**嵌入（玻璃面板内嵌 iframe，视觉风格不变）
- `musicConfig.neteasePlaylistId` 默认填「云音乐热歌榜 3778678」作演示，注释标注「改成你自己的歌单 ID（歌单页 URL 里 playlist?id=xxx）」——你把 ID 发我或自己填一行即可
- 本地音景播放器保留为备用模式（本地曲目才驱动背景律动；网易云 iframe 受跨域限制无法做频谱律动，这是浏览器硬限制）

### 11. 我补充的增强（11）
- **鼠标跟随光晕**（桌面端）：柔光斑跟随指针渐动，点击时有涟漪环——直接解决「看不到特效」
- **樱花增强**：数量回升、体积加大、微透视摆动，深浅主题分别调对比度
- **文章阅读进度条**：顶部玻璃渐变细条
- **标签页彩蛋**：切走标签页时标题变为「(´･ω･`) 页面飞走了…」，回来复原（纯文本无 emoji）
- **Hero 极光 blob**：背景两团粉紫光斑缓慢漂移呼吸（替代当前静态光斑）
