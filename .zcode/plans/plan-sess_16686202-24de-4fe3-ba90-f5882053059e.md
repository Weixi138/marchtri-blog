# 个人博客最终方案（文档先行 · 动态特效 · 五大新奇功能）

## 已确认需求
- **引擎**：Astro + Fuwari（只用内容引擎：文章/分类/RSS/暗色模式/View Transitions），视觉层 100% 重写
- **风格**：毛玻璃优雅 × 日系可爱（樱花粉/淡紫/暖橙色板、LXGW 文楷字体、大圆角）
- **结构**：Hero 个人卡 + 文章流混合首页
- **新奇功能**（你选定）：命令面板+终端彩蛋、天气×昼夜动态背景、音乐播放器+音频律动、追番/书影页、写作热力图+数据看板
- **自审修复项**：单 Canvas 管理器统一调度动画帧（滚出视口/切后台自动暂停、`prefers-reduced-motion` 降级）、giscus 评论、移动端性能预算
- **部署**：Cloudflare Pages

## 第一步：文档先行（首要交付物）
- **`AGENTS.md`**：给后续 AI 代理的项目指南（技术栈、目录结构、命令、样式 token 约定、功能开关、红线）
- **`docs/01-产品与视觉设计规范.md`**：定位、风格定义、色彩/字体 token、动效原则与验收标准
- **`docs/02-技术架构与性能预算.md`**：架构、组件设计、Canvas 管理器机制、首屏 JS 预算、Lighthouse 目标
- **`docs/03-功能需求清单.md`**：五大新奇功能 + 基础功能的详细需求与验收标准
- **`docs/04-内容写作指南.md`**：frontmatter 规范、写作约定
- **`docs/05-部署指南.md`**：Cloudflare Pages 两种路线

## 第二步：模板落地
克隆 Fuwari 合并进项目（保留 docs/ 与 AGENTS.md，重置为自己 git 仓库）→ `pnpm install` → dev 跑通。

## 第三步：主题视觉重写
- 粉紫色板 token 体系（深浅双模式）、毛玻璃组件体系（导航/卡片/侧栏/播放器统一质感）、LXGW 文楷
- **动态特效**：全站 Canvas 动态背景、Hero 打字机+光晕呼吸、滚动入场编排、页面转场、点击樱花粒子、樱花飘落层（均接入 Canvas 管理器，独立开关）

## 第四步：五大新奇功能
1. **命令面板 + 终端彩蛋**：`Ctrl+K` 毛玻璃命令面板（全文搜索/页面跳转/主题切换/特效开关）；`~` 呼出伪终端，支持 `ls`（列文章）、`read <标题>`（打开正文）、`theme`、`help` 等命令
2. **天气×昼夜动态背景**：Open-Meteo 免费 API（无需 key）获取访客当地天气 + 当地时间 → 雨滴滑落/飘雪/星空/黄昏光晕/晴天光斑五种场景；拒绝授权定位时按时间降级
3. **音乐播放器 + 音频律动**：悬浮毛玻璃播放器（本地音频文件，Web Audio API AnalyserNode 驱动背景光晕随节奏律动），文章可插入播放卡片
4. **追番/书影页**：Bangumi API 拉取收藏数据（构建时抓取 + 本地缓存），毛玻璃卡片墙展示
5. **写作热力图 + 数据看板**：构建期扫描文章元数据 → GitHub 式贡献热力图、总字数/文章数/分类分布/年度报告
6. **giscus 评论**（自审补充项）：文章页底部，毛玻璃皮肤

## 第五步：内容与细节
4 篇示例中文文章、关于页、favicon/OG、404 页；所有功能在 `config.ts` 有独立开关。

## 第六步：验收与部署
`pnpm build` 零报错 → 浏览器截图验收桌面+移动端（对照 docs 验收清单逐项过）→ `wrangler pages deploy`（需你完成 Cloudflare 浏览器授权）。

## 交付物
AGENTS.md + 5 份 docs + 完整可运行博客（含全部选定功能）+ 部署脚本与说明。
