# 主题精修方案：保留粉系毛玻璃，重做布局 + 全面打磨细节

## 目标（已与你确认）
- 配色保留樱花粉/淡紫/暖橙毛玻璃风，**不动特效层**（樱花、天气背景、加载动画等全部保留）
- 导航：左侧竖坞 → **顶部悬浮玻璃条**（滚动收缩，符合 docs/01 原设计）
- Banner：外链随机图 → **纯 CSS 渐变装饰 Banner**（可控、加载快）
- 侧栏：从左侧移到**右侧**，内容成为视觉主体
- 全面精修细节质感：统一 token、重做 Fuwari 遗留的旧组件布局

---

## 一、设计 Token 统一（地基，解决"双色板并存"）

现状问题：`tokens.css` 定义了品牌色 `--sakura/--murasaki`，但 Fuwari 遗留的 `variables.styl` 仍用 `oklch(... var(--hue))` 驱动 `--primary`、按钮、链接、选区等几十个变量——两套色并存且细节色不统一。

**改动：**
1. `src/styles/tokens.css`：补齐 docs/01 承诺但未实现的别名变量（`--primary`→樱粉、`--accent`→淡紫、`--bg-base`、`--text-main`、`--text-sub`），新增按钮圆角、导航高度等精修 token；深浅两套同步。
2. `src/styles/variables.styl` 去 hue 化：`--primary` 绑定 `var(--sakura)`，`--btn-regular-bg` 系、`--link-*`、`--selection-bg`、`--title-active`、`--toc-*` 等改为 `color-mix` 樱粉基调的固定值——品牌色不再漂移，Fuwari 体系组件自动品牌化。
3. `--card-bg` 对齐 `--bg-glass`，消除文章页外层与普通卡片两套底色。

## 二、导航重做：顶部悬浮玻璃条

1. 重写 `src/components/Navbar.astro`：
   - 桌面：顶部居中悬浮玻璃胶囊条（毛玻璃+描边+柔影），左侧樱花 Logo + 站名，右侧**文字链接**（首页/归档/看板/照片/关于）+ 命令面板 + 明暗切换；当前页樱粉高亮；下滚时收缩高度。
   - 移动端：同条内 Logo + 汉堡按钮，展开玻璃下拉菜单（参考现有 `widget/NavMenuPanel.astro`）。
2. `src/styles/main.css` L290-340 左坞样式（`#navbar-wrapper`/`.nav-dock`/`.dock-btn`）整体替换为顶栏样式。
3. `src/layouts/MainGridLayout.astro`、`Layout.astro` L405-421 的 navbar-hidden 逻辑适配新结构。

## 三、Banner 重做：纯渐变装饰

1. `MainGridLayout.astro`：删除外链随机图与 **L56-58 的 JSX 残留碎片**（现存 bug）；Banner 改为半透明粉→紫→暖橙多层渐变叠在天气天空 canvas 上（保留"会呼吸"底色）+ 大光斑/樱花枝 SVG 剪影装饰 + 底部玻璃过渡。
2. `src/constants/constants.ts` 高度精修：首页 65vh → 约 52vh，内页 35vh → 约 32vh。
3. `src/config.ts`：清空 `banner.src` 外链。
